# 03: 走通骨架 —— 硬编码分镜到可播放 final.mp4

**What to build:** 本项目的 tracer bullet。刻意**不做任何智能**：三个硬编码分镜（各一句占位旁白 + 一张随仓库分发的占位图），走完整条链路——取图 → 配音 → 按时间轴合成 → 烧字幕 → `final.mp4`。目的是先把管道打通、把 ffmpeg 参数调对，之后再逐个阶段增厚。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 成片时长与音频时长偏差 < 1 秒
- [ ] 字幕在成片中可见（中文字体正常显示，不出现方块）
- [ ] 三个分镜的画面切换点与硬编码时间轴一致
