## 口径

```
lvs run <拍摄稿.md> --task <卡号> --style jp-youth-manga-bw \
        --visual photo --source local --force
```

- `--visual photo`：所有 beat（含图表）都翻译成可拍场景 → **全部走生图**，不出本地排版卡片。
- `--source local`：所有实拍镜用本地 ComfyUI 出图，不联网下载。
- `--style jp-youth-manga-bw`：黑白漫画风（票 44）。
- **串行**：一条跑完再开下一条（8 GB 显存下生图不可并发）。

| 阶段 | 单量 | 耗时 |

| 生图（本地 ComfyUI，Z-Image Turbo，1344×768，8 步） | 1 张 | **≈30 s** |

## 途中排掉的两个坑

1. `pkill -f "lvs run"` 在 Git Bash 下**没杀掉**上一条进程 → 两个 `lvs run` 同时生图，
   GPU 打满、速率掉到 60 s/张。改用 `MSYS2_ARG_CONV_EXCL='*' taskkill /F /T /PID <winpid>` 清掉，恢复 30 s/张。
2. Git Bash 把 `/d/fanshu/...` 转义成 `\d\fanshu\...` → "拍摄稿不存在"。脚本里改用 `D:/fanshu/...`。
