### 二、★ 重要教训：Git Bash 的 `/proc` PID ≠ Windows PID

**这是本次真正的坑，代价是杀错了一个进程。**

- 我用 `ls /proc` + 读 `/proc/<pid>/cmdline` 找到 chain_gen，得到 PID **2060**；
- `taskkill //PID 2060 //T //F` 报"成功终止"——**但 P4 继续在出图**；
- 改用 **psutil** 一查，真正的 chain_gen 是 **PID 9240**，另有一个孤儿 gen 是 **PID 18272**；
- 杀掉 9240 后，P4 立刻停止 → 证实 9240 才是真身。

**结论**：
1. **Git Bash `/proc` 显示的是 MSYS 虚拟/缓存 PID，不是 Windows PID**，且会保留已死进程的残留目录。
2. 杀进程**必须**用 psutil（`process_iter(['pid','name','cmdline'])`）拿真实 PID + 命令行。
3. `taskkill //PID <MSYS PID>` 会杀掉**另一个完全无关的 Windows 进程**——本次误杀了 PID 2060（父进程 1768）。
   事后核查：ComfyUI（1284/3412/8152/22580）、`lvs voice MM01`（25352/29464）均存活，主要服务未受影响，但**误杀本身是真事故**。

**可复用做法**（写进记忆，下次直接照做）：
```python
# 找进程（anaconda 有 psutil）
import psutil
for p in psutil.process_iter(['pid','name','cmdline','create_time']):
    cl = ' '.join(p.info['cmdline'] or [])
    if 'chain_gen' in cl or 'gen_images' in cl:
        print(p.info['pid'], cl)
# 杀进程树
kids = p.children(recursive=True)
for c in kids: c.kill()
p.kill()
```
> ⚠️ 另一个坑：**PowerShell 工具在当前沙箱下不可用**（`Get-CimInstance` 返回空或报 sandbox 错误），
> **Bash 调 `powershell.exe` 被安全策略拦截**。所以列进程只能用 psutil 或 tasklist。

| 1 | **全局道具淋洒**（最严重） | 预设 `昭和青年黑白漫画.json` 的 7 条年代考据道具被 `load_preset()` **无条件拼进每条提示词**，含 `green public telephone booth and rotary-dial phone`。旧版 **1780/1780 条全中** → 每张图都长出电话机/唱机/黑胶/书堆/台灯，窗外一律是山间疗养院。**连 P3 的东京场景都被画成带雪山的疗养院** |
