### L2 补齐了什么（原先断在三处）

L2 原先处于本项目最典型的"**半接线**"状态 —— `_workflow_for` 会选模板，
但**没有任何代码把图送进去**。三处断点都接上了：

| 断点 | 现在的实现 |
|---|---|
| ① 没有上传能力 | 新增 `ComfyClient.upload_image()`（手写 multipart，**不引入 requests 依赖**），把定妆照送进 ComfyUI 的 `input/` |
| ② `generate()` 没有参考图参数 | 新增 `generate(ref_image=…)` + `REF_IMAGE` / `DENOISE` 占位符 |
| ③ 模板文件不存在 | 新增 `workflows/zimage_scene_ref.json`（LoadImage → ImageScale(中心裁切) → VAEEncode → KSampler → VAEDecode → SaveImage） |

### 判据（谁用参考图、谁不用）

`assets._reference_for()` —— **三条全满足**才给参考图：

1. 配了 `[cast].ref_workflow`
2. 本镜提示词里含人物槽位（`{NAOKO}`）
3. 该角色 **`bindable`**（已批准 **且** 参考图文件真的在）

> **第 3 条为什么不能省**：未批准 = "这张脸还没定下来"。
> 拿一张未批准的候选去锚定，等于把未审核的脸固化成全集标准 ——
> 比不给参考图更糟，因为它是**一致地错**。

`assets._workflow_for(config, ref_available=…)` —— **先取图、再选模板**。
顺序反了会出现"选了参考图模板却没有图可喂"，那时报错离根因很远。

### 开跑前会告诉你用没用上

因为 L2 有**三处会悄悄失效**，`lvs assets` 现在会先汇总一次：

```
[参考图 L2] 1/3 镜会用**冻结的定妆照**作参考图（img2img 低去噪）
[参考图 L2]   2 镜回退纯文生图：本镜无人物槽位
```

**不许让"没生效"看起来像"生效了"** —— 这是这一块最重要的设计约束。

### 真机验证（不是"应该能跑"）

| 验的什么 | 结果 |
|---|---|
| 上传参考图 | ✅ 定妆候选 1.39 MB 送进 ComfyUI `input/` |
| 参考图模板出图 | ✅ 1344×768，40.6s |
| 走完整条 `lvs assets` | ✅ 3 镜：1 镜走 img2img、2 镜回退文生图，退出码 1（一镜 Pexels 逐镜失败） |
| ComfyUI 侧核对 | ✅ `/history` 里那一条确实含 `LoadImage` 节点 |
| 对照图 | `docs/参考图对比-L2验证.png`（定妆照 / 纯文生图 / denoise 0.55 / 0.78 / 本次真机产物，五图并排） |

> ⚠️ **我看不了图**（当前模型不支持读图）。所以"画得像不像"必须**你来看** ——
> 对照图已经做好，打开就是五张并排。这是本项目的第一纪律（改了出图相关必须看产物），
> 而我看不了，只能把判据交给你。

**调参旋钮**：`[cast].ref_denoise`（默认 0.55）。v2 方案给的区间是 0.45–0.60，
**太高换脸、太低换不出场景**。逐镜调它即可，不用改模板。

## 四、★★ 另一个静默失效：人脸巡检（Q006/Q007）**一直是死的**

这是本轮新查出来的，和一致性不是一回事，但同样严重。

`lvs qc` 有两条检查：

- **Q006**：空镜里检出人脸（项目注释里写着这是"**Z-Image 最顽固的失败模式**"）
- **Q007**：人物镜没检出人脸

它们依赖 `[qc].face_model`。实测结果：

| 环节 | 结果 |
|---|---|
| 文件存在 | ✅ 232,589 字节 |
| `cv2` 装了 | ✅ OpenCV 4.10.0 |
| `cv2.FaceDetectorYN.create()` | ❌ **报错**（`Can't read ONNX file`） |
| `onnxruntime` 加载 | ✅ 能加载（结构确实是 YuNet：cls/obj/bbox/kps × 3 尺度） |
| 但输出**退化** | ❌ `obj` 恒为 **0**；`cls` 对**纯黑图与人像给出几乎相同的值**（0.775 vs 0.775） |

**结论：这个权重文件不可用**，于是那两条检查**一次都没真正跑过**，
而巡检报告看起来一切正常 —— 典型的**静默降级**。

### 已改为"大声说出来"

- `lvs qc` 会打印：`[巡检] ⚠ 人脸检测不可用 —— Q006/Q007 本次没有检查` + 原因 + 怎么修
- `lvs doctor` 新增检查项 `人脸检测`，同源判据（`qc.face_model_status`，**一处定义两处共用**）

### 怎么修

放一个**可用的**人脸模型：

```powershell
# 官方 YuNet（OpenCV Zoo 的 face_detection_yunet_2023mar.onnx）
# 放到仓库 models/yunet.onnx，或改 [qc].face_model 指过去
```

> 注意：我**没有**替你换模型 —— 那需要下载并把"换个模型后 Q006 判得准不准"
> 在真图上验一遍（本项目纪律：**校验器的价值全在报得准**，不准的校验器比没有更糟）。
> 你要是想让我做，说一声。
>
> 暂时不需要人脸检查的话，设 `[qc].enable_faces = false` —— 这样它不再提示，
> 你也不会误以为查过了。
