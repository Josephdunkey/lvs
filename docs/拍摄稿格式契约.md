# 拍摄稿格式契约（v2）

> 这是 `lvs` 解析器的**输入契约**。按本文件写出来的拍摄稿，`lvs parse` 能做到零降级、零人工回填。
> 由 `lvs/parse.py` 的现有实现反推 + v2 新增字段（标注 ⭐ 的是 v2 新增）。
> 校验命令：`lvs check <拍摄稿.md>`（v2 待实现，见 §7）。

---

## 0. 一句话

**一篇 Markdown，三级标题分场景，正文按句断行，画面意图单独成行写在所辖旁白之后，文末一张画面位清单表。**

---

## 1. 文件骨架（必须照抄这个层级）

```markdown
# <集标题>                          ← H1，只取第一个

## 一、传达层                        ← 固定章名，含三个标签块
**【标题】**
> <一行标题卡文案>

**【冷开场】**（0:00–0:30，<任意说明>）
> <片头旁白，可多行，每行一句>

**【封面文案】**
> 行1：<…>
> 行2：<…>
> 行3：<…>
> 画面建议：<…>

## 二、正文讲稿                        ← 固定章名，正文全在这里
### 【① 场景名】0:00–1:07            ← H3 = 场景；`【名】` + 时间码
<旁白，一句一行>

<旁白，一句一行>
[画面位] <画面意图>

### 【② 场景名】1:07–2:30
…

## 三、画面位清单                      ← 固定章名，表格
| 时间 | 画面 | 素材建议 |
|---|---|---|
| 0:00 | <…> | <…> |

## 四、留存自检                        ← 整章排除，不进 TTS / 不进字幕
## 五、史实核验                        ← 同上
```

**硬性要求**：

| 项 | 要求 | 违反后果 |
|---|---|---|
| 章名 | 必须含「传达层」「正文」「画面位清单」这些**关键词**；分类靠关键词匹配 | 整章被丢进 `other`，静默丢失 |
| 时间码 | `0:00–1:07` 用 `–` `—` `~` `至` 任一分隔；片尾写「结尾」 | 段起始时间记为 `None`，只能靠累计 |
| 场景标题 | **必须** `### 【名】<时间码>`；`【】` 不能省 | 该段被判为「未命名段」 |
| 旁白 | **一句一行**，行间留空行。**不要整段** | 整段会变成一个 shot，配音节奏全错 |
| 画面位 | 独立成行 `[画面位] …`，写在**它管的那段旁白之后** | 归属错位，画面与旁白对不上 |

## 2. 三类行的语法（解析器只认这三个前缀）

| 前缀 | 含义 | 去向 |
|---|---|---|
| `[画面位] <描述>` | 该镜的画面意图 | → `shot.visual` → 提示词 |
| `[重参与点…]` | 互动设计（"如果你是…"） | → `excluded`，**不进 TTS** |
| `> <文本>` | 引用块 | → `excluded`，**不进 TTS**（**块语义**：`>` 行 + 其后到空行/结构边界的整块一起排除，2026-10-04 起） |

**行内提示**（会被自动剥离，保留其余文字）：`（转场）` `（停顿）` `（停）` `（留白）` `（重音）` `（渐入）` `（渐出）`。

**独立方括号 `[xxx]`**：不在上面三类之列的，会被收进 `uncertain`，**需要你复核**。所以别乱用方括号。

---

## 3. 旁白写作规范（决定 TTS 与字幕质量）

```
✅ 一句一行。短句。留白多于修辞。
❌ 禁止 `**加粗**` 脚手架行 —— 会被 TTS 逐字读出来
❌ 禁止在旁白里写「（转场）」以外的括号说明
❌ 禁止把画面描述混进旁白行（会念出来）
```

- 标注：引原文的行以 `〔引原文〕` 或 `> 〔原文〕` 起首（**整块走 `excluded`，块语义已落地**，见 §7 第 4 项）
- 语速：现役音色实测 **3.93 字/秒**；排期按「字数 ÷ 3.7」估更稳
- 镜间静音：`0.3s`（`config.toml [voice].gap`）

## 4. ⭐ 画面位行 v2 语法（本次新增，解决"模型乱画"的根因）

v1 的画面位是一句自由文字，模型会**字面画出引号里的字、箭头的两边、剪辑动词**。
v2 加**显式标注**，让解析器能正确分流，不再靠关键词猜。

### 4.1 两种 kind

```markdown
[画面位] [场景] <可实拍的画面描述>
[画面位] [图表] <屏幕上排版出来的信息>
```

| 标注 | 去向 | 渲染方式 |
|---|---|---|
| `[场景]` | `kind=scene` | 送 ComfyUI 生图 |
| `[图表]` | `kind=graphic` | 本地 Pillow 排版成卡片，**不占显存** |

**不写标注**时解析器用关键词猜（`prompting.classify()`），猜错的会进 `uncertain` 清单。
**写了标注就不会猜错。**

### 4.2 一条画面位可以拆多个 beat

```markdown
[画面位] [场景] 空无一人的草地，杂草覆径 → [场景] 井口吞没一切的黑
```

箭头 `→` 拆成 2 个 beat，各自出图。**但**：

- 数据串（`时间轴：前403 → 前313`）里的箭头是**数据**，不会被拆
- 带 `：` 的模板头（`分栏：…`）整行算**一条**设计

### 4.3 画面位里绝对不要出现的写法（Z-Image Turbo 是 cfg=1.0 蒸馏模型，**完全没有负向引导**）

| 禁止 | 原因 | 正确写法 |
|---|---|---|
| `no people` / `没有人` | 否定句里的名词会被**原样画出来** | 直接写场景里有什么 |
| `no text` / `无文字` | 同上，越排除越多 | 靠全局风格后缀统一压制 |
| `in the style of <艺术家名>` | 会画出**那个人本人** | 用「技法+媒介+调色板」描述 |
| 引号里的字幕原文 `"斩首四万"` | 会被画成**伪汉字/乱码** | 放 `[图表]` 走卡片渲染 |
| 纯剪辑动词 `并排浮现` `砸屏` `高亮` | 它描述"怎么剪"，不是"屏幕上有什么" | 写实际画面 |
| 年代考据道具清单 | 会被无条件拼进每条提示词 → 每张图都长同一批道具 | 道具只写该镜**环境里真有**的 |
| `blank` / `empty` / `plain` 密集的空镜 | 画面越空，模型越要**自己补一个人** | 改成有纹理/光影的实体（灰泥墙、麻布、水面） |
| 中文镜头术语 `中景, 平视` | 模型不吃中文术语 | 由 `LEX_*` 词库映射成 `medium shot` / `eye level` |

### 4.4 ⭐ 人物槽位语法（v2 新增，一致性核心）

**人物名必须用定妆卡里登记的 ID**，解析器据此把定妆锚定描述注入该镜提示词：

```markdown
[画面位] [场景] {NAOKO} 侧身走过校墙，背景只有枯枝与墙
[画面位] [场景] {WATANABE} 与 {NAOKO} 并肩走在草地上，两人间隔一米
```

- `{NAME}` 会被替换成 `cast/lock.json` 里该人物的**冻结描述**（见《出图流程 v2》§3）
- **不写 `{NAME}` 的人物不会被定妆绑定**，模型自由发挥 → 变脸
- 多人同框必须**逐个写出**，解析器会加「几人」前缀 + 个体差异锁定句

#### 4.4.1 简称与别名

写简称也可以 —— 只要它在定妆卡的标题括号里登记过：

```markdown
### 渡边彻（わたなべ とおる / 渡边 / "我"）
```

登记了 `渡边` 之后，画面位写「渡边在草地上」照样会绑定到 `渡边彻`。

> ⚠ **没登记的简称会静默漏掉**：那一镜**根本不注入锚定**，不报错、不警告，
> 只是画面里的脸变成随机采样。所以定妆卡的别名要写全。
> 复核方式：`lvs migrate` 跑完后，检查 `_v2/*-迁移报告.md` 的槽位统计。

#### 4.4.2 ⭐ 代词声明（v2 新增，可选但强烈建议）

画面位里大量用代词指人（`{NAOKO} 左手握住他的手`）。只换姓名不换代词，
那一镜就只注入了一个人的锚定。

**代词的作用域是"这一集讲谁"，不是"这本书有谁"** —— 所以在**拍摄稿头部**声明，
不在定妆卡里声明：

```markdown
> 代词：她={NAOKO}，他={渡边彻}
```

放在 H1 标题与正文之间的元信息区（`>` 引文块里）即可，`lvs migrate` 会读第一处匹配。

| 层级 | 写法 | 适用 |
|---|---|---|
| 集级（**推荐**） | 拍摄稿头部 `> 代词：她={NAOKO}` | 「她」在全书中泛指四人，但在本集只指直子 |
| 书级 | 定妆卡里 `- 代词：我（第一人称叙述者）` | 「我」全书只指渡边，写一次到处生效 |
| 本次 | 命令行 `--pronoun 他=渡边彻` | 一次性的人工判断，优先级最高 |

**优先级**：命令行 > 拍摄稿行 > 定妆卡。**书级声明只在全书唯一时才自动生效**
（两个人物都声明 `他` → 判为歧义 → 不换，列进迁移报告交给人）。

机器**不猜**歧义代词的理由：猜错等于给那一镜注入**另一个人的脸** ——
不报错、不崩，只是悄悄产出错图。这是本项目最怕的一类故障。

同理，`lvs migrate` 会把「**疑似比较提及**」（`与渡边彻龄` vs `与渡边彻并肩`，
句式相同、语义相反）单列一节交人复核 —— 已按出场处理，但列出来让人有机会推翻。

## 5. 画面位清单表（文末表格）

```markdown
## 三、画面位清单

| 时间 | 画面 | 素材建议 |
|---|---|---|
| 0:00 | 草地，一口被草遮住的井 | 生图：黑白漫画，芒草坡 |
| 0:30 | 蝉壳留在树干上 | 素材库：002/H/049.png |
```

- 至少 3 列；不足 3 列的行会被跳过并记 `notes`
- 第一列时间码支持 `0:30` / `1:02:03` / `结尾`
- **这张表用于人工核对**，`lvs` 不直接消费它（但 v2 会用它做**覆盖率校验**：正文里的画面位数量应与表里条数一致）

## 6. 密度与节奏（质量红线）

| 指标 | 基准 | 校验 |
|---|---|---|
| 画面位密度 | **约 100 汉字 / 条** | `< 150` 告警 |
| 单组长尾 | 单组 > 200 汉字即需回补画面位 | 校验脚本按「所辖旁白块」算 |
| 画面位归属 | 按「句后第一个画面位」归属，**管它前面的句子** | 校验脚本必须用这个模型 |
| 单章镜头数 | 45–135 镜（实测区间） | — |

## 8. 给你（作者）的一句话指令

要让 Agent / 拆书技能产出的稿子满足本契约，直接给这句：

> 按 `docs/拍摄稿格式契约.md` 出稿。三级标题分场景带时间码；旁白一句一行、短句、留空行；
> 画面意图写 `[画面位] [场景] …` 或 `[画面位] [图表] …`，写在所辖旁白块之后；
> 出现具名人物时写 `{NAME}` 占位符（名字取定妆卡登记名）；文末附画面位清单表。
> 头部元信息区加一行 `> 代词：她={…}，他={…}`（本集实际用到的代词）。
> 不写否定句，不写艺术家名，不写剪辑动词。
