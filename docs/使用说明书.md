# LongVideoStudio 使用说明书

> 写给**没用过命令行**的人。
> 不需要懂编程。按顺序照做就行 —— 每一步都告诉你「会看到什么」和「报错了看哪里」。

---

## 第 0 章 这东西到底是干嘛的

**一句话**：你把写好的文字稿交给它，它自动做成一条**带画面、有旁白、有字幕的视频**。

打个比方，它像一条**自动厨房的流水线**：

```
你写好菜谱（稿子）  →  它切成一道道工序  →  每道工序做出半成品  →  最后装盘（成片 mp4）
```

它替你干的四件事：

| 工序 | 它做什么 | 你要做什么 |
|---|---|---|
| ① 拆镜 | 把稿子切成一个个"镜头"，每个镜头配一句话和一张图的意思 | 写好稿子 |
| ② 配画面 | 给每个镜头找图（从你的图片文件夹找，或自己画） | 准备图片 |
| ③ 配音 | 把旁白读出来，生成音频和字幕 | 基本不用管 |
| ④ 合成 | 把图 + 声音 + 字幕拼成一个 mp4 | 基本不用管 |

**关键理解**：它不是"点一下出大片"。它是一条**流水线** —— 每一道工序都会把半成品**存到硬盘上**。所以：

- 中途断了、电脑关了，**下次接着跑，不用从头**；
- 任何一步不满意，你可以**只重做那一步**；
- 每个半成品你都能打开看（图片、音频、字幕、分镜表都是普通文件）。

---

## 第 1 章 先说清楚：它能做什么、不能做什么

### 能

- 一集视频从文字稿一路做到 `final.mp4`
- 断点续跑（中断了不用重来）
- 每一步产物都能看、能改、能单独重做
- 一次做多集（每集一个"任务名"，互不干扰）

### 要注意（这些是真话，别踩）

| 现实 | 说明 |
|---|---|
| **要慢** | 如果让它自己画图，一张图约 20 秒。一集 200 个镜头 ≈ 1 小时以上。用你自己的图片就快得多 |
| **显卡有上限** | 8GB 显存（比如 RTX 4060 笔记本）**不能同时**跑"自己画图"和"本地配音"，两者抢显存。用免费的联网配音（edge）就没这问题 |
| **画面质量取决于素材** | 它找的图来自你的图片文件夹；文件夹里没有合适的图，它就找不到 |
| **版权你自己负责** | 用别人的图片、音乐之前，请自行确认授权 |
| **不做字幕翻译、不做剪辑特效** | 它只做"图 + 旁白 + 字幕"这条线 |

## 第 2 章 三条路线，按你的条件挑一条

先挑路线，再往下看对应的章节。**建议从 A 开始**（1 分钟，什么都不用准备）。

| 路线 | 需要准备什么 | 能得到什么 | 大概耗时 |
|---|---|---|---|
| **A. 先看看效果** | 什么都不用 | 一条 11 秒的示例片（画面是色块，只为证明流程通） | **1 分钟** |
| **B. 做出你自己的成片** ⭐ | ① 一份稿子 ② 一个放图片的文件夹 | **有画面、有真人配音、有字幕的成片**（不需要 API key，不需要显卡） | 十几分钟 |
| **C. 全自动出图** | 上面全部 + 一个 AI 画图的 key（或本地 ComfyUI） | 不用自己准备图，它按文字自动画 | 1 小时以上 |

> ⭐ **路线 B 是最划算的**：不用花钱、不用显卡，就能做出真能看的成片。本手册会用最大篇幅讲它（第 5 章）。
>
> 路线 A 走完就知道"我这边环境是好的"；路线 C 属于进阶，见第 8 章。

## 第 3 章 把它装好（第一次用才需要）

### 3.1 你需要一台电脑

- **Windows 10/11**（本手册以 Windows 为例）
- 装好 **Python 3.10 或更新**（[python.org](https://www.python.org/downloads/) 下载，安装时**勾选 "Add Python to PATH"**）

### 3.2 打开"命令行"

别怕，它就是**打字的窗口**。

- 按 `Win` 键 → 输入 `powershell` → 回车
- 会跳出一个黑框框，光标在闪 —— 这就是我们要的地方

**怎么算"成功输入了一条命令"**：敲完按回车，等一下，屏幕上有字出来 = 成功。

### 3.3 把程序装到你的电脑上

把项目文件夹放到一个**路径里没有空格**的地方，比如 `D:\LongVideoStudio`。

然后在命令行里，**一行一行**敲（每行按回车，等它跑完再敲下一行）：

```powershell
cd D:\LongVideoStudio                        # 进入项目文件夹（改成你自己的实际路径）

python -m venv .venv                         # 建一个独立环境（约 30 秒）

.venv\Scripts\python.exe -m pip install -e ".[tts,http]"    # 装依赖（约 1 分钟）

copy config.example.toml config.toml         # 把配置模板复制成你的配置
```

> **为什么要 `.venv`**：给这个项目一个"独立的工具箱"，不和你电脑上别的 Python 项目打架。

### 3.4 做个"体检"，确认装好了

```powershell
.venv\Scripts\python.exe -m lvs doctor
```

**你会看到**（大意）：

```
LongVideoStudio 环境体检  (lvs 0.1.0)
------------------------------------------------------------
[通过] Python：3.12.7
[通过] ffmpeg：ffmpeg version 7.1
[警告] ffprobe：未找到（…降级解析，精度足够）
[缺失] LLM key：app.openai_api_key 未填写
[警告] ComfyUI：未启动
------------------------------------------------------------
```

**怎么看这份报告**：

| 标记 | 含义 | 要做什么 |
|---|---|---|
| `[通过]` | 好 | 不用管 |
| `[警告]` | 没它也**能跑**，只是某些功能少一点 | 一般可以先不管 |
| `[缺失]` | 缺了它某个功能**用不了** | 看它下面的 `↳` 提示怎么做 |

> **看到 "LLM key 未填写" 不用慌** —— 那是路线 C 才要的东西。路线 A 和 B 都不需要。
>
> **看到 "ComfyUI 未启动" 也不用慌** —— 那只是"自己画图"功能没开。

> 如果以后嫌 `.venv\Scripts\python.exe -m lvs` 太长：项目里有个 `scripts\lvs.cmd`，
> 把它所在目录加进系统的 PATH，之后直接敲 `lvs` 就行。

## 第 5 章 做出你自己的第一集（路线 B，重点章节）

一共 6 步。**别跳步**，每步都往下看"会看到什么"。

---

### 第 1 步：写一份稿子

建一个文件，比如 `D:\我的视频\我的稿.md`（`.md` 是普通文本文件，用记事本也能编）。

**最小可用的模板**（照这个格式写，`##` 和 `[画面位]` 是它认的标记）：

```markdown
# 001-我的第一集 拍摄稿

## 一、传达层

**【标题】**
> 我的第一集

**【冷开场】**（0:00–0:08，从最戏剧的一刻切入）
> 那天，我终于动手了。

---

## 二、正文讲稿

### 【① 开头】0:00–0:08

那天，我终于动手了。

[画面位] [场景] 一片安静的草地，清晨的光

### 【② 过程】0:08–0:18

过程比想象中难。

[画面位] [场景] 桌上的笔记本，摊开着
```

**三个规矩**：

1. 每段用 `### 【① 名字】开始时间–结束时间` 开头
2. **要说的话直接写**（它会读成旁白）
3. **要什么画面**写在 `[画面位]` 那一行 —— **这一行最重要**，它决定去你文件夹里找哪张图

---

### 第 2 步：准备图片文件夹（**命名是关键**）

建一个文件夹，比如 `D:\我的视频\图片`，把你手头的照片/图片放进去。

> **最重要的规矩：图片的文件名要包含"画面里有什么"的词。**
>
> 它就是**靠文件名去猜**哪张图配哪个镜头的。名字没意义的图，它认不出来。

| ✅ 好名字 | ❌ 白瞎 | 为什么 |
|---|---|---|
| `草地.png` | `IMG_20231001.jpg` | 镜头写"一片安静的**草地**"，`草地` 命中 |
| `清晨的光.jpg` | `DSC_0042.jpg` | 镜头写"**清晨的光**"，命中 |
| `笔记本.png` | `微信图片_20231001.png` | 镜头写"桌上**的笔记本**"，命中 |

**文件夹本身的名字也算**（比如放在 `清晨\` 文件夹里的图，都算带"清晨"这个词）。

> 💡 想给一张图加更多关键词、又不想改名？在图片旁边放一个**同名 `.txt`**，
> 里面一行一个词。例如 `IMG_001.jpg` 旁边放 `IMG_001.txt`，内容：
> ```
> 草地
> 清晨
> 安静
> ```
> 这张图就会被当成"同时有这三个词"。

---

### 第 3 步：告诉它图片在哪

打开 `config.toml`（用记事本），找到 `[library]` 这一段，改成你的文件夹：

```toml
[library]
dirs = ["D:\\我的视频\\图片"]     # ← 改成你的路径。注意：Windows 路径里的 \ 要写成 \\
recursive = true
min_score = 1
```

同时在同一个文件里，确认配音用的是**免费联网**的那种：

```toml
[tts]
backend = "edge"                 # edge = 免费、联网、不用 key
voice = "zh-CN-YunxiNeural"      # 男声。想要女声改成 zh-CN-XiaoxiaoNeural

[voice]
align = "estimate"               # 用估算的方式对齐字幕（不用装额外的语音识别）
```

> ⚠️ **路径要写双反斜杠** `\\`。`D:\我的视频\图片` 是对的写法，写单斜杠会报错。

---

### 第 4 步：让它先"认一遍"你的图片

```powershell
.venv\Scripts\python.exe -m lvs library
```

**你会看到**：

```
  - D:\我的视频\图片
  产物：…\.work\_library\library-index.json
  分布：image 24
```

`image 24` = 认到 24 张图。**数字是 0 就要检查路径写对没有。**

---

### 第 5 步：把稿子读进来（parse）

```powershell
.venv\Scripts\python.exe -m lvs parse "D:\我的视频\我的稿.md" --task 我的第一集
```

> `--task 我的第一集` 是**给这一集起的名字**。所有半成品会存在 `.work\我的第一集\` 里。
> 名字随你起，但**前后要一致**。

**你会看到**：

```
  分镜：2 个
  画面位清单：2 条
  产物：…\.work\我的第一集\parse.json
```

---

### 第 6 步：拆成一个个镜头（shots）

```powershell
.venv\Scripts\python.exe -m lvs shots --task 我的第一集 --no-llm --source library
```

**你会看到**：

```
  产物：…\.work\我的第一集\shots.json
  [note] 未使用 LLM（已指定 --no-llm）：…prompt/keywords/source 为启发式结果
```

> **`--no-llm`** = 不花钱、不用 key，用简单的规则拆。
> **`--source library`** = 画面一律从你的图片文件夹找。
>
> 💡 这一步产出的 `shots.json` 是**你能手动改的表**。如果某个镜头找错图了，
> 打开它，找到那一镜，把 `library_asset` 填成某张图的完整路径 —— 它就是你要的那张。
> （这是官方设计的用法，不是"违规操作"。）

---

### 第 7 步：开始找图（assets）⭐ 最容易卡的一步

```powershell
.venv\Scripts\python.exe -m lvs assets --task 我的第一集 --source library
```

**成功的样子**：

```
素材获取完成：新取 3，跳过 0，失败 0（共 3 镜）
  来源：library 3
```

**如果有镜头失败**，它会告诉你**为什么**，比如：

```
失败明细（前 10）：
  - shot 001：素材库没找到匹配的图（关键词：我的第一）
      两个办法：① 把图片改名为包含这些关键词（如「草地.png」）；
                ② 或配好 LLM key 让拆镜给出更好的关键词
```

**怎么办？** 三个办法，从简单到麻烦：

1. **改名**：把某张图改名成含那个关键词的名字（比如加一张 `我的第一.jpg`）
2. **手动指定**：打开 `shots.json`，给这一镜的 `library_asset` 填上一张图的路径
3. **跳过它**：让这一镜当"空镜"，等下合成时用纯色底

> 失败**不可怕**，它会把成功的镜都保留。改好之后**重跑同一条命令**，
> 成功的会自动跳过，只补失败的（这叫"幂等"，是你的朋友）。

---

### 第 8 步：配音 + 字幕（voice）

```powershell
.venv\Scripts\python.exe -m lvs voice --task 我的第一集
```

**你会看到**：

```
配音完成：合成 3，跳过 0，失败 0
  整轨：…\.work\我的第一集\audio\narration.mp3（8.6s）
  字幕：…\.work\我的第一集\subtitle.srt（3 行）
```

> 这一步**需要联网**（用的是微软的免费语音合成）。没网会失败。

---

### 第 9 步：拼成成片（build）

```powershell
.venv\Scripts\python.exe -m lvs build --task 我的第一集
```

**你会看到**：

```
合成完成：…\.work\我的第一集\final.mp4
  画面轨 8.6s｜旁白 8.7s｜成片 8.6s（偏差 0.03s）
  字幕：已烧录
```

**打开看**：

```powershell
start .work\我的第一集\final.mp4
```

🎉 **有画面、有旁白、有字幕的成片，出来了。**

---

### 以后再做新的一集

重复第 1～9 步，**只把 `--task` 换个新名字**即可。

如果嫌一条条敲麻烦，第 5～9 步可以合并成一条：

```powershell
.venv\Scripts\python.exe -m lvs run "D:\我的视频\我的第二集.md" --task 我的第二集 --no-llm --source library
```

## 第 6 章 那六个"关卡"是什么

跑 `lvs run` 的时候，你可能会遇到它**停下来**，说"等审批"：

```
▶ 下一道要过的门：G0·拍摄稿 —— 结构 / 否定式 / 人物槽位
```

**这是什么？** 它给你设了 **6 道人工确认关卡**，目的是**别让你白跑几小时**：

| 关卡 | 名字 | 它在问什么 | 为什么值 |
|---|---|---|---|
| G0 | 拍摄稿 | 稿子写对了吗？ | 稿子错一个字，后面几百张图全白做 |
| G1 | 分镜与提示词 | 切出来的镜头对不对？ | 跑之前先看一眼，比跑完再看便宜 |
| G2 | 定妆参考 | 人物的脸定下来了吗？ | 脸没定，跨镜头就会"变脸" |
| G3 | 分镜图与巡检 | 这几百张图有没有整批崩？ | **最贵的一步**，要边跑边查 |
| G4 | 配音与字幕 | 音画对得上吗？ | 合成完再返工最贵 |
| G5 | 成片 | 能交付了吗？ | 最后一关 |

**怎么过？**

```powershell
.venv\Scripts\python.exe -m lvs gate --task 我的第一集              # 看现在卡在哪
.venv\Scripts\python.exe -m lvs gate --task 我的第一集 --approve G0 --note "看过了，没问题"
```

- 觉得不行就打回：`--reject G0 --note "第三段要重写"`
- 这道门对本次不适用：`--skip G0 --note "纯空镜集，没有人物槽位"`

> **`--note` 是必填的**（打回和跳过时必须写原因）。别嫌麻烦 ——
> 三天后的你，会感谢现在的你写了原因。

**如果只是想快速试一下**，可以在 `run` 后面加 `--skip-gates` 一次跑完（不推荐日常用，等于放弃了这些保护）。

## 第 7 章 出错了怎么办（对照表）

| 你看到的 | 什么意思 | 怎么办 |
|---|---|---|
| `python` 不是内部或外部命令 | 电脑不认 `python` | 重装 Python，**记得勾 "Add Python to PATH"** |
| `未找到 xxx 配置文件` | 没有 `config.toml` | 跑 `copy config.example.toml config.toml` |
| `未找到 …parse.json。请先运行：lvs parse` | 上一步没做 | 按它说的先做上一步。**它挺老实的，会告诉你缺什么** |
| `素材库没找到匹配的图` | 图片文件名没含关键词 | 见第 5 章第 7 步的三个办法 |
| `ComfyUI 未启动或不可达` | 它想"自己画图"，但你电脑上没开画图服务 | 路线 B 不需要画图。**看上面失败明细的第一行**，真正的原因通常是"素材库没找到" |
| `Pexels key 未配置` | 想从网上找图但没有 key | 路线 B 不需要。加 `--source library` 只用你的本地图片 |
| `配音失败` / 卡在 voice | 多半是没网 | 连上网重跑 `lvs voice --task 名字` |
| `显存不足` / 卡死 | 同时跑了画图和本地配音 | 二选一：`[tts] backend = "edge"`（联网配音不占显存） |
| 成片是**黑屏** | 画面没接上 | 看它提示的"黑屏占比"。多半是 assets 有镜失败，重跑 `lvs assets` |
| 成片**没声音** | 配音没合进去 | 确认 `[tts] backend` 不是 `silent`（那是静音测试用） |
| 跑到一半断了/关了电脑 | 没事 | **重跑同一条命令**，已完成的会跳过 |
| `磁盘空间` 报错 | 半成品占地 | `lvs clean --all` 先看会删什么（默认**不删**），确认后加 `--yes` |

### 万能的排查三步

```powershell
.venv\Scripts\python.exe -m lvs doctor --task 我的第一集    # 1. 环境有没有问题
.venv\Scripts\python.exe -m lvs gate --task 我的第一集      # 2. 卡在哪一关
.venv\Scripts\python.exe -m lvs board --task 我的第一集     # 3. 整体进度一览
```

## 第 8 章 想做得更好（进阶，可选）

| 想要 | 做什么 | 在哪配 |
|---|---|---|
| **画面更贴题**（镜头关键词更聪明） | 配一个 AI 文本 key | `config.toml` 的 `[app] openai_api_key`，然后重跑 `lvs shots --task 名 --force` |
| **不用自己准备图，让它画** | 启动 ComfyUI（需显卡） | `config.toml` 的 `[comfyui]`；启动脚本 `scripts\start_comfyui.cmd` |
| **从网上找图** | 配 Pexels key | `config.toml` 的 `[pexels] api_key` |
| **换画面风格** | 看一眼有哪些可选 | `lvs styles` 列出全部（30 个内置，按题材分组） |
| **换个说话的声音** | 改配音音色 | `[tts] voice = "zh-CN-XiaoxiaoNeural"`（女声）等 |
| **只重做某几个镜头** | 见下面「怎么改单独一个镜头」 | — |
| **看图/改图** | 开图形界面 | `lvs gui`（浏览器里操作） |
| **边做边问** | 交互向导 | `lvs studio`，它会在关键处停下来问你 |

### 怎么改单独一个镜头

**情况一：它找错了图**（最常见）

1. 打开 `.work\你的任务名\shots.json`（普通文本，记事本能开）
2. 找到那一镜（按 `"id":` 找），把 `"library_asset"` 改成你想要的那张图的完整路径：
   ```json
   "library_asset": "D:\\我的视频\\图片\\正确的图.png"
   ```
3. 删掉它之前复制过去的那张（在 `.work\你的任务名\assets\library\` 里找 `shot-001.png` 这种名字）
4. 重跑 `lvs assets --task 你的任务名 --source library`

**情况二：整批都不满意，想全部重来**

```powershell
lvs assets --task 你的任务名 --source library --force
```

> ⚠️ `--force` 会**全部重做**（已成功的不再跳过），长任务慎用。
>
> ⚠️ 常见的坑：`lvs assets --only` 的 `--only` 是筛**素材来源**（`pexels,local,graphic,library`），
> **不是筛镜号**。只有 `lvs qc --only` 才是按镜号筛（`--only 1-20,35`）。

## 第 9 章 名词表（听到这些词别懵）

| 词 | 大白话 |
|---|---|
| **任务（task）** | 就是你给这一集起的名字，比如 `我的第一集`。所有半成品按它分文件夹 |
| **分镜（shot）** | 一个镜头。一段旁白 + 一张图 |
| **素材 / assets** | 每个镜头的画面（一张图或一段视频） |
| **拆镜（shots 阶段）** | 把稿子切成一个个镜头 |
| **门禁（gate）** | 那 6 道人工确认关卡 |
| **幂等** | "重跑不重复劳动"。已经做完的会跳过，只补没做完的 |
| **断点续跑** | 中断了，下次从断的地方接着跑 |
| **提示词（prompt）** | 给"自己画图"功能看的一句话描述。不用画图的话不用管它 |
| **ComfyUI** | 一个本地画图软件。"让它自己画图"时才会用到 |
| **ffmpeg** | 拼视频的工具。**已经内置了，不用自己装** |
| **`.work` 文件夹** | 所有半成品都在这儿。删了不会丢你的原稿和图片，只是要重跑 |
| **silent / placeholder** | 两个"假"后端，用来测试流程。真做片别用 |

## 第 10 章 命令速查

> 下面 `PY` 代表 `.venv\Scripts\python.exe`。如果你把 `scripts\lvs.cmd` 加进了 PATH，就把 `PY -m lvs` 换成 `lvs`。

```powershell
# ── 体检与查看 ──────────────────────────────
PY -m lvs doctor                     # 环境体检
PY -m lvs gate --task 名字            # 看流水线卡在哪一关
PY -m lvs board --task 名字           # 进度看板
PY -m lvs styles                     # 有哪些画面风格可选

# ── 一次跑通 ────────────────────────────────
PY -m lvs run --demo                                        # 演示（1 分钟，什么都不用）
PY -m lvs run "稿.md" --task 名字 --no-llm --source library   # 用本地图片做真成片

# ── 一步一步来 ──────────────────────────────
PY -m lvs library                                     # 认一遍图片文件夹
PY -m lvs parse "稿.md" --task 名字                    # 读稿
PY -m lvs shots --task 名字 --no-llm --source library  # 拆镜
PY -m lvs assets --task 名字 --source library          # 找图
PY -m lvs voice --task 名字                            # 配音+字幕
PY -m lvs build --task 名字                            # 拼成片
PY -m lvs publish --task 名字                          # 投稿物料（带字封面+标题+简介+标签）

# ── 调整 ────────────────────────────────────
PY -m lvs shots --task 名字 --force            # 强制重拆镜（配了 LLM key 之后用）
PY -m lvs assets --task 名字 --force           # 强制重新找图（长任务慎用，会全部重做）
PY -m lvs qc --task 名字 --only 12,15-18       # 只巡检这几个镜（注意：这个是按**镜号**筛）
PY -m lvs gate --task 名字 --approve G0 --note "原因"   # 过一道关卡
PY -m lvs clean --all                          # 看看能清多少（默认不删）

# ── 图形界面 ────────────────────────────────
PY -m lvs gui        # 浏览器里点着用
PY -m lvs studio     # 终端里一步步问你
```

## 附：一页纸的完整流程（可以贴墙上）

```
准备：稿子(.md) + 一个装图片的文件夹（图片名要有意义的词）

config.toml 改两处：
    [library] dirs = ["D:\\你的\\图片文件夹"]
    [tts]     backend = "edge"

然后：

  lvs doctor                       ← 体检（有 [缺失] 才需要处理）
  lvs library                      ← 认图片（确认张数不为 0）
  lvs parse 稿.md --task 名字       ← 读稿
  lvs shots --task 名字 --no-llm --source library
  lvs assets --task 名字 --source library     ← 失败了就按提示改名/指定
  lvs voice --task 名字             ← 需要联网
  lvs build --task 名字             ← 完成！成片在 .work\名字\final.mp4
  lvs publish --task 名字           ← 投稿物料在 .work\名字\publish\（封面已叠字）

中途断了？重跑同一条命令就行，已完成的会跳过。
```
