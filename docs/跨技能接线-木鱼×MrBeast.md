# 跨技能接线 · 木鱼水心 × MrBeast

> 回答「怎么用木鱼式的风格，做出野兽先生式的传达效果」。
> 本文是**接线手册**，不是两套方法论的并列介绍。两个技能各自怎么用，看各自 SKILL.md。

---

## 零、一句话结论

**不是二选一，也不是"融合"，是乘法分工。**

> **木鱼层管 AVD（让人看完），野兽层管 CTR（让人点进来）。**
> 二者正好是 MrBeast 公式 `成功 = CTR × AVD` 的两个乘数 —— 它们**不是竞争关系，是缺一不可**。

木鱼式内容本身**就是对的**：30 分钟长视频，AVD 绝对值天然高（30min × 50% = 15min），
算法会给推荐。**唯一要补的是 CTR 这一半**。

---

## 一、为什么能搭：各自强的正好是对方弱的

| | 木鱼水心 | MrBeast |
|---|---|---|
| **强项** | AVD｜深度层（时代/思潮/立场/意象）、一期一完整故事线、评述有推理链 | CTR｜标题公式、封面三要素、前 30 秒 Hook 结构、re-engagement 节奏 |
| **弱项** | 标题封面平淡、前 30 秒慢热、长段落无转折标记 | 深度薄；10–20 分钟撑得住，40 分钟撑不住 |
| **一句话** | **留得住人，拉不进来** | **拉得进来，留不住 40 分钟** |

→ 互补是**结构性的**，不是风格上的折中。所以接线点很清晰：**只把野兽层接到木鱼层的"帧边界"上。**

---

## 二、三条真冲突 + 一条仲裁原则

| # | 冲突 | 木鱼 | 野兽 | 怎么办 |
|---|---|---|---|---|
| 1 | **语体** | 诚恳·朴实·深情·忧伤，**零戏谑零商业感** | 靠情绪强度、喊叫式 hook | 借**结构**不借**语气** |
| 2 | **时长** | 25–45 分钟 | 10–20 分钟 | 不改时长。长视频是 AVD 优势，**不要为了节奏切短** |
| 3 | **节奏** | 曲线是**渐深**（认知密度递增） | 曲线是**渐高**（刺激强度递增） | 不照抄，做**转译**（见 §五） |

### ★ 仲裁原则（本文最重要的一条）

> **野兽层只作用于「帧边界」，不得进入「句子层」。**

- **帧边界**（野兽层可进）：标题、封面、0–8 秒冷开场、章节之间的缝、收尾最后一句。
- **句子层**（木鱼专属）：正文每一句讲述、评述的推理链、举例、原文引用。

理由：木鱼的人设信任度**正是靠句子层建立的**。一旦"家人们""你敢信吗"进入正文，
观众会立刻判定"这是个标题党频道"——CTR 短期涨，**AVD 长期塌**，乘法结果是负的。

## 三、分层接线表（谁在哪一环上班）

| 环节 | 木鱼 | 野兽 | 合成规则 |
|---|---|---|---|
| **选题** | 一期一条完整故事单元 | 一句话测试 | **双向过滤**：既是完整故事线，又能一句话勾人。过不了任一条就砍 |
| **标题** | 已给 3 路子（金句/反常识/问题钩子） | 数字前置、8 词内、不用感叹号 | 保留木鱼 3 路子，**再加 1 条"故事里的极端事实"**。4 选 1 |
| **封面** | 自产漫画底图 + 三行大字 | 脸 + 物 + 问题；zoom-out 测试 | 木鱼的**画面风格** + 野兽的**三要素构图**。禁夸张表情 |
| **冷开场** | 「① 冷开场」段 | 0–3s 概念即画面 / 3–8s 赌注 / 8–15s 视觉预告 | ★ **唯一的重点手术位**，见 §四 |
| **正片** | 全权 | **禁止进入** | 一个字不改 |
| **章节缝** | 已有分节（①②③…） | 每 3–5 分钟一次 re-engagement | 轻量介入：**只在分节处加一句"悬念前置句"**（见 §四） |
| **评述** | 五步推理链 = **AVD 引擎** | — | 全权木鱼。**野兽不碰**（碰了就成"观点输出"变"情绪输出"） |
| **收尾** | 落回一句原文、对"你"说 | CTA / 下一期悬念 | 木鱼的深情收束 + **最后一句加下一期钩子** |
| **投稿物料** | `bilibili-package.md` 五件套 | 标题/封面规范 | 直接复用，野兽层补进"标题"与"封面"两项 |

## 四、只改 3 个位置（可执行的手术点）

不要"全面融合"。**90% 的收益来自这 3 处，改错了也容易回滚。**

### 手术 1 · 冷开场（0–8 秒）

木鱼的冷开场**已经做对了 1/4**（"概念即画面"它本来就是）。缺的是后两件：

| 位置 | 野兽要求 | 拿现有稿举例（P1「开篇即结局」） |
|---|---|---|
| 0–3s | 概念即画面 | ✅ 已有：`这片草地上，有一口井。谁也不知道它在哪儿。` |
| 3–8s | **赌注** | ⚠️ 实际有，但埋得太浅：`掉进去，就再也找不回来了。` → **提到前 8 秒** |
| 8–15s | **视觉预告** | ❌ 缺。补一句"这一期会讲到的三个画面"，**不剧透结论** |
| 15–30s | 开始行动 | ✅ 木鱼本来就直接进故事 |

> ⚠️ **不要为了"赌注"改成"如果这期你不看完，你就……"**——那是野兽的语气，会毁人设。
> 木鱼的"赌注"天然长在故事里（那口井 / 直子的请求），**只要提前，不要发明。**

### 手术 2 · 章节缝（这里收益最大）

实测最大转折间隔 **652 秒（近 11 分钟）无转折标记** —— 这是最致命的一处。
但**不要往评述里塞"但是""结果"**（那是词表骗自己）。正确做法是**在已有分节边界**加一句：

| 分节 | 加什么 | 例 |
|---|---|---|
| ①→②的缝 | 一句**悬念前置**：先说不懂的地方，再讲 | `但这一章最冷的地方，不是那口井。` |
| ②→③的缝 | 一句**代价声明**：指出接下来要付什么 | `要讲清楚这件事，得先回到一九六九年。` |
| ③→④的缝 | 一句**判断前置**：把最强判断的结论先露一半 | `你会看到一个你以为是深情、其实是残忍的安排。` |

> 只加**过渡句**，不改任何内容。三句话的成本，换回整条留存曲线。

### 手术 3 · 标题 + 封面

- 标题：木鱼现有 3 路子保留，**追加第 4 路「故事里的极端事实」**
  - 例（画皮）：`他带回家一个绝色美人，直到扒开她的皮`
  - 例（枕中记）：`他做了个梦，醒来时小米饭还没熟`
- 封面：木鱼现有"三行大字 + 母题镜底图"**已经接近野兽要求**，只补两点——
  1. **Zoom-out 测试**：缩到手机首页大小，还能看清吗？
  2. **问题感**：三行里必须有一行让人产生疑问，而不是陈述

## 五、节奏曲线的转译（★ 不要照抄 stair-stepping）

MrBeast 的阶梯递进原理是**多巴胺耐受**：强度不涨 = 观众感觉在掉。
这条原理对讲书**完全适用**，但**燃料不同**：

| | 野兽的燃料 | 木鱼的燃料（转译后） |
|---|---|---|
| 强度指什么 | 更大、更疯狂、赌注更高 | **更接近真相**、更反直觉 |
| 每一段承诺 | "接下来更刺激" | "接下来你会知道一件你原本想不到的事" |
| 曲线形态 | 刺激强度递增 | **认知密度递增 + 情感浓度递增** |
| 证据 | 画面/规模升级 | **一条比上一条更硬的判断**（对应 newmuyu 的"非直觉"门槛） |

> 关键：**newmuyu 的"三条硬门槛"（非直觉/归因/反面）就是木鱼的 stair-stepping 燃料。**
> 每条判断都能涨一级，"这里往下更深夜"的感觉就有了 —— 而且**一个字的语气都不用改**。

## 六、实测证据（不是感觉，是跑出来的）

用野兽技能的留存检查器跑现有木鱼稿：

```bash
python <mrbeast>/scripts/retention_curve_checker.py <拍摄稿>.md
```

**第一次跑（直接喂拍摄稿）** → **49/100，D 级**

| 发现 | 严重度 |
|---|---|
| 前 30 秒三件套缺：赌注、视觉预告 | 中 |
| 最长 652 秒无转折标记（阈值 180s） | 高 |
| 强度曲线斜率 −0.04/分钟，整体**下降** | 高 |

**但这里有陷阱。** 拍摄稿头部有 `> 档位：…` `> 代词：…` `**【标题】**` `**【冷开场】**`
`**【封面文案】**` 等**非正文包装段**。脚本把它们当正文算进了 0–30 秒 —— **判据扫错了东西**。

剥掉元数据、只喂 `## 二、正文讲稿` 之后重跑 → **51/100，D 级**

| 发现 | 真伪 | 说明 |
|---|---|---|
| 前 30 秒缺 **数字锚点/赌注/视觉预告** | ⚠️ **部分假** | 脚本靠词表匹配。`掉进去，就再也找不回来了` 实际**就是赌注**，但没命中词表 → **漏判** |
| 最长 **652 秒**无转折标记 | ✅ **真** | 评述段太长太沉，是真的结构缺口 |
| 强度曲线平坦 | ✅ **真** | 渐深曲线在"词频代理指标"下确实测不出上升 |

> ★ **两条必须记住的诚实边界**：
> 1. **脚本对"拍摄稿"格式不适配** —— 先剥掉传达层元数据再跑，否则 0–30 秒判据看的是包装。
> 2. **词表匹配会漏判** —— 别把"缺少赌注"当成事实去改稿，先回去读那句话。
>    （这正是"判据自己会说谎，先问扫描范围覆盖到了吗"。）

**结论**：真洞只有 1 个半（转折间隔 + 曲线形态），**恰好都在"章节缝"这个手术点上**。
所以 §四 的手术 2 是投入产出比最高的一处。

## 七、红线：5 条野兽手段，讲书场景绝对不能用

| # | 手段 | 为什么不能用 |
|---|---|---|
| 1 | **标题党**（承诺不兑现） | 木鱼人设靠"不骗你"建立。且野兽自己也说：要"点击价值"不要"点击诱饵" |
| 2 | **喊叫式 hook**（"家人们""你敢信吗"） | 直接摧毁语体四项（诚恳朴实深情忧伤） |
| 3 | **封面夸张表情脸** | 长视频讲书观众**反感**这个；且木鱼禁止作者正面肖像，只能用角色的侧影 |
| 4 | **中段插"点赞订阅"** | 野兽自己也不做；打断评述推理链 = 直接掉 AVD |
| 5 | **为"极端"编造数字** | 触碰 newmuyu 去 AI 味的 **L1 硬规则：假精确数字**。且违反"专名一律回原文核对" |

## 八、落地：两条命令串起来跑

```bash
# ① 木鱼自检：结构占比 + 引用逐字校验 + 去AI味 + 术语泄漏
python <newmuyu>/scripts/audit_script.py <讲稿>.md <原书分章目录> --theory

# ② 野兽自检：前30秒三件套 / 转折间隔 / 强度曲线
#    ★ 必须先剥掉传达层元数据，只喂「## 二、正文讲稿」之后的部分
python <mrbeast>/scripts/retention_curve_checker.py <剥好的纯正文>.md
```

两条各管一头，互不冲突：
- `audit_script.py` 守的是**内容与合规**（引用 ≤15%、六段占比 55–65%、术语为 0）
- `retention_curve_checker.py` 守的是**传达与节奏**（0–30 秒、3–5 分钟一次 re-engagement）

**交付前两个都要绿。** 但注意：**两个脚本抓的都是"结构缺失"，抓不出"创意本身不好"** ——
最终仍要人工看一眼。

## 九、一页速查卡

| 问题 | 答案 |
|---|---|
| 会打架吗 | 不会，是乘法。木鱼=AVD，野兽=CTR |
| 怎么分 | 野兽只碰**帧边界**，木鱼全权**句子层** |
| 改哪几处 | **3 处**：冷开场、章节缝、标题+封面 |
| 节奏怎么转译 | stair-stepping → **认知密度递增**（更接近真相，不是更疯狂） |
| 语气能用野兽的吗 | **不能。**借结构不借语气 |
| 怎么验 | 两个脚本都跑；跑留存检查器**必须先剥元数据** |
| 最优先改哪 | **章节缝**（实测最大间隔 652s，真洞） |

### 交付前检查清单

- [ ] 冷开场 8 秒内出现了"赌注"（提前，不发明）
- [ ] 每个章节缝有过渡句，最长无转折间隔 < 180 秒
- [ ] 标题 4 路子各出 1 条，能过"一句话测试"
- [ ] 封面过 Zoom-out 测试，且有一行让人产生疑问
- [ ] 正文里的野兽口吻 = **0 处**
- [ ] `audit_script.py` 绿（引用 ≤15%、术语 0、六段占比达标）
- [ ] 通读一遍：**删掉故事速览后，评述仍有独立价值**
