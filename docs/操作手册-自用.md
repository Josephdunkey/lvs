# LongVideoStudio 操作手册（自用版）

> 写给**你**的。按你的实际环境写的：DeepSeek 拆镜 + 本地 TTS(8100) + ComfyUI 生图 + 黑白漫画风格。
> 目标：晚上回去照着敲，能出片。**带 ⚠️ 的地方是我实测踩过的坑，请务必看一眼。**

## 0. 三十秒总览

**你的机器上要同时存在三个东西**（这是整套流程的全部依赖）：

| 东西 | 干什么 | 启动方式 |
|---|---|---|
| **ComfyUI**（端口 8188） | 出图（你 90% 的镜都靠它） | 双击 `D:\ComfyUI\start_comfyui.cmd` |
| **本地 TTS**（端口 8100） | 配音 | `D:\qwentts\lvs_tts_server.py`（见 §2.2） |
| **DeepSeek key** | 拆镜（已配好，不用管） | 已在 `config.toml` 里 |

**你的工作循环**（一条命令都不用背，照抄）：

```
起 ComfyUI  →  lvs run（出图）  →  关 ComfyUI  →  lvs voice（配音）  →  开着也行  →  lvs build（合成）
```

> ⚠️ **为什么中间要关 ComfyUI**：8GB 显存装不下"生图模型 + TTS 模型"两个。
> 不关的话 `lvs voice` 会直接报错拦下（这是**故意的**，不是 bug）。

## 3. 六道关卡：它为什么老停下来

`lvs run` 默认会在 6 个地方停下来，让你确认。**这不是卡住，是保护**（防止白跑几小时）：

| 关卡 | 停在哪 | 它在问什么 |
|---|---|---|
| **G0** | 拆镜之前 | 稿子写对了吗？（稿子错一个字 → 后面几百张图白做） |
| **G1** | 出图之前 | 切出来的镜对不对？（**这一步最值**：看 `shots.json`） |
| **G2** | 出图之前 | 人物的脸冻结了吗？ |
| **G3** | 配音之前 | 图有没有整批崩？（**最贵的一步**，边跑边查） |
| **G4** | 合成之前 | 配音字幕对得上吗？ |
| **G5** | 交付之前 | 能发了吗？ |

### 三种过闸方式

```powershell
$P = ".venv\Scripts\python.exe"

# ① 看现在卡在哪
& $P -m lvs gate --task NW01P1

# ② 批准（--note 是给你自己看的，别省）
& $P -m lvs gate --task NW01P1 --approve G0 --note "稿子看过了"

# ③ 打回（必须写原因，否则三天后的你不知道要改什么）
& $P -m lvs gate --task NW01P1 --reject G1 --note "第 12 镜画面跑偏了"

# ④ 这道门对这次不适用 → 跳过（也必须写原因）
& $P -m lvs gate --task NW01P1 --skip G2 --note "纯空镜，没有人物"
```

> **G2 你会经常需要 skip** —— 因为只有《挪威的森林》有定妆库，
> 别的书（资治通鉴 / 夜谭十记）没有 `_cast`，G2 没东西可批。

## 4. ⚠️ 你的配置里的两个坑（这次审查专门查出来的）

### 4.1 `source_mode = "auto"` + Pexels key 为空 → 一部分镜必然失败

**问题**：你的 `config.toml` 里
```toml
[shots]
source_mode = "auto"          # ← 让 LLM/规则逐镜决定去哪找素材
[pexels]
api_key = ""                  # ← 但这里是空的
```
`auto` 会把一部分镜判给 Pexels，而那些镜**一定拿不到素材**。
实测：13 镜里有 8 镜本该出图，却因为另外 5 镜要 Pexels 而**整批受影响**。

**怎么改（三选一，推荐第 ①）**：

```toml
# ① 推荐：你的图本来就全靠 ComfyUI 画 → 固定成 local，问题彻底消失
[shots]
source_mode = "local"

# ② 或者：填上 Pexels key（免费申请 https://www.pexels.com/api/）
#    好处是"城市空镜"这类实拍感强的镜能从网上拿现成视频

# ③ 或者：只用某几镜改（编辑 .work/<任务>/shots.json，把 "source" 改成 "local"）
```

> 好消息：**这个坑我已经在代码上兜住了** —— 现在 Pexels 没配 key 只会让**那几个镜**失败，
> 其余镜照常出图（退出码 1 = 有失败件），不会再整批卡死。但把上面改掉更省事。

### 4.2 一份 `config.toml` + 多本书 → 定妆库会串

**问题**：你的 `config.toml` 里
```toml
[paths]
lib = "D:/fanshu/挪威的森林/10-语料/知识视频素材库"
```
**所有**项目内路径（定妆库、定妆卡、风格文件）都从这一行派生。
所以跑《资治通鉴》时，它会去**挪威的森林**那里找定妆卡 —— 找不到就报错或空转。

**怎么改：给每本书各建一份配置**（一次性，之后一劳永逸）

```powershell
$P = ".venv\Scripts\python.exe"

# 建一份《资治通鉴》的项目配置（会生成 config.资治通鉴.toml）
& $P -m lvs init "D:\fanshu\资治通鉴\10-语料\知识视频素材库" --name 资治通鉴

# 之后跑这本书就带 --config
& $P -m lvs run $稿子 --task ZZTJ01 --config config.资治通鉴.toml
```

> 机器相关的项（ComfyUI 地址 / TTS 服务 / API key）**沿用主 `config.toml`**，不用重配。

## 5. 出错了看这里（对照你的真实环境）

| 你看到 | 真正的原因 | 怎么办 |
|---|---|---|
| **`ComfyUI 不可达`，但你明明开着** | 系统代理把 `127.0.0.1` 也拦了（Clash/VPN 常见） | **已修**：工具现在会绕开代理访问本机。若还不行，检查 `ComfyUI` 窗口有没有报错退出 |
| `GPU 串行冲突：ComfyUI 正在运行` | 你在 ComfyUI 还开着时跑了 voice | 关掉 ComfyUI 窗口，重跑 `lvs voice` |
| `显存不足` / `需要 4600 MB` | 同上，或别的程序占了显存 | 关 ComfyUI / 关浏览器硬件加速 |
| `Pexels key 未配置`（个别镜） | 见 §4.1 | 改 `source_mode = "local"` |
| `素材库没找到匹配的图` | 库策略下关键词没命中 | 你库是空的，正常不会遇到；若遇到见 §4.1 第 ① |
| `TTS 服务不可达 127.0.0.1:8100` | 本地 TTS 没起 | `cd D:\qwentts && python lvs_tts_server.py` |
| `LLM 返回 HTTP 402/401` | DeepSeek 余额或 key 问题 | 去 DeepSeek 后台看余额 |
| **跑到一半断了 / 电脑关了** | —— | **重跑同一条命令**，做过的会跳过（这是它的核心能力） |
| 成片是**黑屏** | 画面轨没接上，多半有镜的图失败了 | 看它提示的黑屏占比；`lvs assets` 补齐失败的镜 |
| 成片**没声音** | 配音没合进去 | 确认 `[tts] backend` 不是 `"silent"`（那是测试用的静音） |
| 字幕有**错别字/时间偏** | 对齐问题 | 你配了 `align = "auto"`（用 whisper）；想快点可临时改 `"estimate"` |

### 三个万能排查命令

```powershell
& $P -m lvs doctor --task NW01P1     # 1. 环境有什么问题
& $P -m lvs gate   --task NW01P1     # 2. 卡在哪一道关卡
& $P -m lvs board  --task NW01P1     # 3. 整体进度一览
```

## 6. 一步一步来（不想用 `run` 的时候）

`lvs run` 是一键脚本；出问题时**拆开敲**更好定位：

```powershell
$P = ".venv\Scripts\python.exe"
$C = "config.toml"
$T = "NW01P1"
```

## 7. 出图质量相关的（你关心的重点）

你的风格是 `jp-youth-manga-bw`（黑白日漫），配置在 `[shots].style`。

**改动图的提示词**：`shots.json` 里每镜有 `prompt` / `visual` / `keywords`。
改完重跑 `lvs assets`（记得先删掉那一镜的旧图，否则会被跳过）。

**换风格**：
```powershell
& $P -m lvs styles                      # 看全部 30 个内置风格（按题材分组）
& $P -m lvs styles 黑白版画              # 只看某一类
```
想加自己的风格：写进 `<素材库>\00-设定\风格预设.toml`，**不用改代码**。

**定妆（人物一致性）**——只有《挪威的森林》配好了：
```powershell
& $P -m lvs cast --lint                 # 检查定妆卡写法（9 条判据）
& $P -m lvs cast --extract              # 从定妆卡抽取到库
& $P -m lvs cast --render               # 出定妆候选图
```
⚠️ 改了定妆卡**必须重跑 `--extract`**，否则库里还是旧的脸。

**巡检（防止整批崩）**：
```powershell
& $P -m lvs qc --task $T                # 全量查
& $P -m lvs qc --task $T --only 1-40    # 只查前 40 镜（大任务边跑边查）
```
> G3 那道门现在**要求你先跑过 `lvs qc`**（否则批准也不放行）——这是我上轮加的，专门防"跑完 10 小时才发现整批崩"。
