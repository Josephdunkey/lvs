也就是说：**测试只验证了"如果 LLM 返回 X，下游会怎样"；"LLM 客户端本身会不会正确拿到 X"从来没验过。**

**风险说明**

1. `extract_json` 是"模型输出 → 结构化数据"的**唯一**转换器。它处理 4 类输入（```` ```json ````围栏 / 裸 JSON / 前后有散文的 JSON / 完全坏掉），错了不会报错，只会让拆镜"少几镜"或"提示词为空"—— 静默产出错产物。
2. `chat_json` 的重试语义（`retries=1` → 最多 2 次尝试）没有任何判据。`shots.py:582` 与 `:732` 都依赖它。
3. `lvs/llm.py:146` `setattr(exc, "raw", text)` 是**动态挂属性**；调用方 `shots.py:585` 紧接着读 `exc.raw`。谁把属性名改成 `raw_text`，静态检查与测试都不会红，运行时才炸。
4. `publish.py:670-704`（`polish_with_llm`）是本轮刚为 B站/抖音投稿加的功能，**函数体整段 0 覆盖**：`--llm` 一旦失败，回退逻辑（"失败自动退回规则文案"）从未被执行验证过。

```python
def _fake_requests(monkeypatch, *, post):
    mod = types.SimpleNamespace(post=post)

    return mod


class _Resp:
    def __init__(self, status_code, body, payload=None):
        self.status_code = status_code
        self.text = body
        self._payload = payload

    def json(self):
        if self._payload is None:
            raise ValueError("not json")
        return self._payload


def test_chat_builds_url_payload_and_headers(monkeypatch):
    seen = {}

    def post(url, json=None, headers=None, timeout=None):  # noqa: A002

        return _Resp(200, "ok", {"choices": [{"message": {"content": "hello"}}]})

    _fake_requests(monkeypatch, post=post)
```

### M06 🟠 架构测试的"豁免表"没有过期检查 —— 死条目实测静默通过

**文件**：`tests/test_architecture.py:365-371`（`_SHOTS_READ_EXEMPT`）、`:270-273`（`_HASH_ALLOWLIST`）、`:321`（`_LEAF_ALLOWED`）

**实测证据（探针 M13）**

我把一条**指向不存在文件**的豁免塞进 `_SHOTS_READ_EXEMPT`：

```python

    ...
    "store.py": "界面只读显示，且用 try_load_shots 容错",
```

原因：唯一守这张表的是 `test_shots_read_exemptions_are_justified`，它只检查 `why.strip()` 非空：


**风险说明**：豁免表是"绕过架构约束"的白名单。它的**过期**有两种形态，都无判据：
1. 文件被改名/删除 → 死条目永远留着（实测已证明）；
2. 某文件**已经不再读 `shots.json`** → 豁免理由成了历史陈迹，但仍被当作"已论证过"。

```python

# lvs/llm.py —— 追加一个传输层协议（不删任何现有 API）
from typing import Protocol


class LLMTransport(Protocol):
    """把"怎么发请求"与"怎么用结果"分开。

    为什么要它：`shots.py` / `publish.py` 现在只能整段换掉 `chat_json`，
    于是"chat_json 自己对不对"永远测不到（coverage 26%）。
    有了这层，测试注入 `FakeTransport`，真实现照样在链路上跑。
    """

    def post_chat(self, url: str, payload: dict, headers: dict, timeout: int) -> dict: ...


class RequestsTransport:
    """默认实现（就是现在的 `LLMClient.chat` 里的那段 requests.post）。"""

    def post_chat(self, url, payload, headers, timeout):  # noqa: ANN001
        resp = requests.post(url, json=payload, headers=headers, timeout=timeout)
        if resp.status_code >= 400:
            raise LLMError(f"LLM 返回 HTTP {resp.status_code}：{resp.text[:400]}")
        return resp.json()


class LLMClient:
    def __init__(self, base_url, api_key, model, timeout=120, transport=None):  # noqa: ANN001
        ...
        self.transport = transport or RequestsTransport()
```

```python
    ...  # 真 chat_json + 真 extract_json 全在链路上，只有 HTTP 被替掉
```

### E. 编码与行尾规范化

见 M05 的 `.gitattributes` / `.editorconfig`。配套一个小工具（**默认 dry-run**）：

```python
# .work/tools/normalize_eol.py —— 新增；默认只报告，--write 才写回
"""把指定目录下的文本文件统一成 LF（`.cmd`/`.bat` 保持 CRLF）。

用法：
    ./.venv/Scripts/python.exe -X utf8 .work/tools/normalize_eol.py --write lvs tests scripts docs
"""

from __future__ import annotations

import argparse
import pathlib
import sys

SKIP_DIRS = {".git", ".venv", "node_modules", "build", "dist", "__pycache__", ".work", ".workbuddy"}
BINARY_SUFFIX = {
    ".png", ".jpg", ".jpeg", ".webp", ".gif", ".mp4", ".mov", ".wav", ".mp3", ".m4a",
    ".onnx", ".safetensors", ".ckpt", ".zip", ".gz", ".pdf", ".ico", ".woff", ".woff2",
}
KEEP_CRLF = {".cmd", ".bat"}


def normalize(raw: bytes, want_crlf: bool) -> bytes:
    fixed = raw.replace(b"\r\n", b"\n")
    return fixed.replace(b"\n", b"\r\n") if want_crlf else fixed


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description="统一行尾为 LF（默认 dry-run）")
    ap.add_argument("paths", nargs="+", help="要处理的目录（必须显式给出）")
    ap.add_argument("--write", action="store_true", help="真正写回；缺省只报告")
    a = ap.parse_args(argv)

    targets: list[tuple[pathlib.Path, bytes]] = []
    for root in a.paths:
        base = pathlib.Path(root)
        if not base.exists():
            print(f"跳过不存在的路径：{base}", file=sys.stderr)
            continue
        for p in sorted(base.rglob("*")):
            if not p.is_file():
                continue
            if any(part in SKIP_DIRS for part in p.parts):
                continue
            if p.suffix.lower() in BINARY_SUFFIX:
                continue
            raw = p.read_bytes()
            fixed = normalize(raw, p.suffix.lower() in KEEP_CRLF)
            if fixed != raw:
                targets.append((p, fixed))

    for p, fixed in targets:
        if a.write:
            p.write_bytes(fixed)
    verb = "已改写" if a.write else "需要规范化（加 --write 生效）"
    for p, _ in targets:
        print(f"  {p.as_posix()}")
    print(f"共 {len(targets)} 个文件{verb}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

**安全提醒**：只在 `git status` 干净时跑 `--write`；跑完立刻 `python -m pytest -q` 确认 1160 passed。
