## §0 方法与归一化口径

### 0.1 三档定义（本文件全文唯一口径）

| 等级 | 判据（满足任一即属本档） | 处置 |
|---|---|---|
| 🔴 **严重** | ① 会出**坏交付**（错片 / 黑帧 / 坏密钥写进配置）；② 会**卡死整条流水线**（含不可中断的挂死）；③ 会**丢工作成果**（未入库、不可恢复）；④ **安全口子可被外部触发** | 必须修复 → 进「紧急」 |
| 🟠 **一般** | 会**静默出错 / 白跑 / 降级难察觉**，或让**续跑 agent 多付成本**，但不直接毁交付 | 建议修复 → 进「次要」 |
| 🟡 **优化** | 可选：一致性问题、死代码、体量组织、工具链未固化、可读性 | 长期按需 |

**定级只看后果，不看修复难度**；也**不因「这是本地工具」而降级**（S03 就是反例：本地服务一样能被任意网页打穿）。
