LongVideoStudio 操作手册（自用版）

写给你的。按你的实际环境写的：DeepSeek 拆镜 + 本地 TTS(8100) + ComfyUI 生图 + 黑白漫画风格。 目标：晚上回去照着敲，能出片。带 ⚠️ 的地方是我实测踩过的坑，请务必看一眼。

0. 三十秒总览

你的机器上要同时存在三个东西（这是整套流程的全部依赖）：

东西 干什么 启动方式
ComfyUI（端口 8188） 出图（你 90% 的镜都靠它） 双击 D:\ComfyUI\start_comfyui.cmd
本地 TTS（端口 8100） 配音 D:\qwentts\lvs_tts_server.py（见 §2.2）
DeepSeek key 拆镜（已配好，不用管） 已在 config.toml 里

你的工作循环（一条命令都不用背，照抄）：

起 ComfyUI  →  lvs run（出图）  →  关 ComfyUI  →  lvs voice（配音）  →  开着也行  →  lvs build（合成）

⚠️ 为什么中间要关 ComfyUI：8GB 显存装不下"生图模型 + TTS 模型"两个。 不关的话 lvs voice 会直接报错拦下（这是故意的，不是 bug）。

1. 今晚第一次跑：照这个顺序

1.1 先体检（30 秒）

cd D:\LongVideoStudio
.venv\Scripts\python.exe -m lvs doctor

看三类标记：[通过] 不用管；[警告] 大多可以先不管；[缺失] 才要处理。

⚠️ 你现在会看到这一条警告，它是真的： [警告] 素材来源策略：source_mode = auto，但 [pexels].api_key 为空 意思是：auto 会让一部分镜去 Pexels 找素材，但你没填 Pexels key， 那些镜必然失败。解决办法见 §4.1（这是我这次审查专门为你的配置加的检查）。

1.2 起两个服务

# 窗口 1：ComfyUI（首次加载模型要 1-2 分钟，别急着敲下一条）
D:\ComfyUI\start_comfyui.cmd

# 窗口 2：本地 TTS
cd D:\qwentts
python lvs_tts_server.py          # 确认它打印出监听 8100

起来后验证一下（新开一个窗口）：

cd D:\LongVideoStudio
.venv\Scripts\python.exe -c "from lvs import imagegen, tts, guard; from lvs.config import Config; c=Config.load('config.toml'); print('ComfyUI:', imagegen.ComfyClient(c.get('comfyui.base_url')).health()); print('TTS:', tts.OpenAISpeechBackend(c.get('tts.base_url')).health())"

两个都应该是 True。 若 ComfyUI 是 False 但你确定它开着 —— 见 §5 的代理那条。

1.3 挑一集跑

以《挪威的森林》为例（它有 8 篇稿子，定妆库也齐）：

$P = ".venv\Scripts\python.exe"
$C = "config.toml"
$T = "NW01P1"                                   # 任务名，自己起，别改来改去
$M = "D:\fanshu\挪威的森林\10-语料\知识视频素材库\05-拍摄稿\01-P1.md"   # ← 改成你实际要跑的那篇

& $P -m lvs run $M --task $T --config $C

然后它会停下来问你（这是设计如此，见 §3）：

⛔ G0·拍摄稿 未放行（还没审）
  看产物：
    D:\fanshu\...\01-P1.md
  下一步（审完挑一条）：
    lvs gate --task NW01P1 --approve G0 --note "看过了，OK"
    ...

看完稿子没问题，就批准；再重跑同一条 run。 一路重复到出片。

💡 嫌麻烦、今晚只想先看效果：加 --skip-gates 一次跑完（等于放弃那 6 道保护）。

2. 三个服务怎么起、怎么关

2.1 ComfyUI（生图，8188）

D:\ComfyUI\start_comfyui.cmd            # 显存吃紧可加 --lowvram
  • 什么时候要开：lvs assets（出图）时
  • 什么时候必须关：lvs voice（本地配音）之前 —— 否则显存不够，工具会拦住你
  • 怎么关：直接关那个窗口

2.2 本地 TTS（配音，8100）

cd D:\qwentts
python lvs_tts_server.py
  • 什么时候要开：lvs voice 时
  • 你的音色配置在 config.toml 的 [tts]：voice-F-clean-youth， mode = "clone"，参考音频在 D:\fanshu\村上春树\...\_voice_probe\ref-F-full.wav
  • 不想用本地 TTS（比如它坏了，但你要先出个能看的片）： 把 [tts] backend 临时改成 "edge" —— 免费联网、不占显存、不需要开这个服务。

2.3 DeepSeek（拆镜）

已在 config.toml 配好，不用起服务、不用管。只有 lvs shots 那一步用它。

3. 六道关卡：它为什么老停下来

lvs run 默认会在 6 个地方停下来，让你确认。这不是卡住，是保护（防止白跑几小时）：

关卡 停在哪 它在问什么
G0 拆镜之前 稿子写对了吗？（稿子错一个字 → 后面几百张图白做）
G1 出图之前 切出来的镜对不对？（这一步最值：看 shots.json）
G2 出图之前 人物的脸冻结了吗？
G3 配音之前 图有没有整批崩？（最贵的一步，边跑边查）
G4 合成之前 配音字幕对得上吗？
G5 交付之前 能发了吗？

三种过闸方式

$P = ".venv\Scripts\python.exe"

# ① 看现在卡在哪
& $P -m lvs gate --task NW01P1

# ② 批准（--note 是给你自己看的，别省）
& $P -m lvs gate --task NW01P1 --approve G0 --note "稿子看过了"

# ③ 打回（必须写原因，否则三天后的你不知道要改什么）
& $P -m lvs gate --task NW01P1 --reject G1 --note "第 12 镜画面跑偏了"

# ④ 这道门对这次不适用 → 跳过（也必须写原因）
& $P -m lvs gate --task NW01P1 --skip G2 --note "纯空镜，没有人物"

G2 你会经常需要 skip —— 因为只有《挪威的森林》有定妆库， 别的书（资治通鉴 / 夜谭十记）没有 _cast，G2 没东西可批。

4. ⚠️ 你的配置里的两个坑（这次审查专门查出来的）

4.1 source_mode = "auto" + Pexels key 为空 → 一部分镜必然失败

问题：你的 config.toml 里

[shots]
source_mode = "auto"          # ← 让 LLM/规则逐镜决定去哪找素材
[pexels]
api_key = ""                  # ← 但这里是空的

auto 会把一部分镜判给 Pexels，而那些镜一定拿不到素材。 实测：13 镜里有 8 镜本该出图，却因为另外 5 镜要 Pexels 而整批受影响。

怎么改（三选一，推荐第 ①）：

# ① 推荐：你的图本来就全靠 ComfyUI 画 → 固定成 local，问题彻底消失
[shots]
source_mode = "local"

# ② 或者：填上 Pexels key（免费申请 https://www.pexels.com/api/）
#    好处是"城市空镜"这类实拍感强的镜能从网上拿现成视频

# ③ 或者：只用某几镜改（编辑 .work/<任务>/shots.json，把 "source" 改成 "local"）

好消息：这个坑我已经在代码上兜住了 —— 现在 Pexels 没配 key 只会让那几个镜失败， 其余镜照常出图（退出码 1 = 有失败件），不会再整批卡死。但把上面改掉更省事。

4.2 一份 config.toml + 多本书 → 定妆库会串

问题：你的 config.toml 里

[paths]
lib = "D:/fanshu/挪威的森林/10-语料/知识视频素材库"

所有项目内路径（定妆库、定妆卡、风格文件）都从这一行派生。 所以跑《资治通鉴》时，它会去挪威的森林那里找定妆卡 —— 找不到就报错或空转。

怎么改：给每本书各建一份配置（一次性，之后一劳永逸）

$P = ".venv\Scripts\python.exe"

# 建一份《资治通鉴》的项目配置（会生成 config.资治通鉴.toml）
& $P -m lvs init "D:\fanshu\资治通鉴\10-语料\知识视频素材库" --name 资治通鉴

# 之后跑这本书就带 --config
& $P -m lvs run $稿子 --task ZZTJ01 --config config.资治通鉴.toml

机器相关的项（ComfyUI 地址 / TTS 服务 / API key）沿用主 config.toml，不用重配。

5. 出错了看这里（对照你的真实环境）

你看到 真正的原因 怎么办
ComfyUI 不可达，但你明明开着 系统代理把 127.0.0.1 也拦了（Clash/VPN 常见） 已修：工具现在会绕开代理访问本机。若还不行，检查 ComfyUI 窗口有没有报错退出
GPU 串行冲突：ComfyUI 正在运行 你在 ComfyUI 还开着时跑了 voice 关掉 ComfyUI 窗口，重跑 lvs voice
显存不足 / 需要 4600 MB 同上，或别的程序占了显存 关 ComfyUI / 关浏览器硬件加速
Pexels key 未配置（个别镜） 见 §4.1 改 source_mode = "local"
素材库没找到匹配的图 库策略下关键词没命中 你库是空的，正常不会遇到；若遇到见 §4.1 第 ①
TTS 服务不可达 127.0.0.1:8100 本地 TTS 没起 cd D:\qwentts && python lvs_tts_server.py
LLM 返回 HTTP 402/401 DeepSeek 余额或 key 问题 去 DeepSeek 后台看余额
跑到一半断了 / 电脑关了 —— 重跑同一条命令，做过的会跳过（这是它的核心能力）
成片是黑屏 画面轨没接上，多半有镜的图失败了 看它提示的黑屏占比；lvs assets 补齐失败的镜
成片没声音 配音没合进去 确认 [tts] backend 不是 "silent"（那是测试用的静音）
字幕有错别字/时间偏 对齐问题 你配了 align = "auto"（用 whisper）；想快点可临时改 "estimate"

三个万能排查命令

& $P -m lvs doctor --task NW01P1     # 1. 环境有什么问题
& $P -m lvs gate   --task NW01P1     # 2. 卡在哪一道关卡
& $P -m lvs board  --task NW01P1     # 3. 整体进度一览

6. 一步一步来（不想用 run 的时候）

lvs run 是一键脚本；出问题时拆开敲更好定位：

$P = ".venv\Scripts\python.exe"
$C = "config.toml"
$T = "NW01P1"

# 1) 读稿（免费、可反复跑）
& $P -m lvs parse "D:\fanshu\挪威的森林\10-语料\知识视频素材库\05-拍摄稿\01-P1.md" --task $T --config $C

# 2) 拆镜（用 DeepSeek；想不花 key 加 --no-llm）
& $P -m lvs shots --task $T --config $C

# 3) 出图（★ 需要 ComfyUI 开着）
& $P -m lvs assets --task $T --config $C

# 4) 配音（★ 需要 ComfyUI 关掉 + 本地 TTS 开着）
& $P -m lvs voice --task $T --config $C

# 5) 合成
& $P -m lvs build --task $T --config $C

成片在：D:\LongVideoStudio\.work\<任务名>\final.mp4

中途想改

# 某个镜找错图 → 编辑 .work\<任务>\shots.json 里那一镜的字段，然后
& $P -m lvs assets --task $T --source local --only local     # 只重做本地生图这一支

# 整批不要了，全重来
& $P -m lvs assets --task $T --force

# 只重出某几个镜的图（先删掉它们的图，再重跑）
Remove-Item ".work\$T\assets\local\shot-012.png"
& $P -m lvs assets --task $T

9. 一页纸速记

【每晚开工】
  1) D:\ComfyUI\start_comfyui.cmd          ← 窗口1，等它加载完
  2) cd D:\qwentts && python lvs_tts_server.py  ← 窗口2

【跑一集】
  3) cd D:\LongVideoStudio
  4) .venv\Scripts\python.exe -m lvs run "<稿子>" --task <名>
  5) 遇到关卡 → lvs gate --task <名> --approve G0 --note "..."
                然后重跑第 4 步
  6) 出图那步做完 → 关掉 ComfyUI 窗口（腾显存给配音）
  7) 继续跑 → 成片在 .work\<名>\final.mp4

【出事就三个命令】
  lvs doctor / lvs gate / lvs board

【永远记住】
  · 断了就重跑，做过的会跳过
  · 关了 ComfyUI 再配音（8GB 显存装不下两个）
  · 打回/跳过一定写 --note，三天后的你会感谢现在的你

附：状态说明

本手册基于 2026-10-03 的代码状态。这一轮审查（第十一轮）为你修了 5 个真 bug：

  1. 本机服务被系统代理拦掉 → 开着 ComfyUI 却报"不可达"（新增 lvs/net.py，本机一律绕代理）
  2. 全新项目第一次 lvs run 连 parse 都不跑就卡在 G0，还让你"看产物"（列表空的）
  3. Pexels key 为空时整个 assets 阶段硬失败 → 本该出图的镜一张都不出
  4. Config.load("config.toml") 传字符串直接崩，报 AttributeError（一句人话都没有）
  5. doctor 不认识 silent 配音后端 → 对着正常配置报"未知后端"

另外新增了 doctor 的"素材来源策略"检查，专门在花钱之前发现 §4.1 那个矛盾。
