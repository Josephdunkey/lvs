# 参考图（L2）效果演示

> 2026-10-03 晚生成。**同一份稿子、同一组 seed**，跑两遍，
> 唯一差别是 `[cast].ref_workflow` 开没开 —— 这样对比才公平。

## 先看哪个

| 顺序 | 文件 | 看什么 |
|---|---|---|
| **1** | `参考图A-B对比.png` | **最省时间**。整图 2×4 网格 + 脸部放大对比，一眼看出两组差别 |
| **2** | `参考图对比-左A纯文字-右B带参考.mp4` | 左右并排的成片（15.7s，有配音有字幕）。左＝A，右＝B，同时播放 |
| 3 | `成片A-纯文字锚定.mp4` / `成片B-带参考图.mp4` | 单独看某一组的完整成片 |

## 这次比的是什么

稿子（`.demo/稿.md`）是同一份，三个镜头刻意选了**不同景别/光线**，
因为"脸稳不稳"只有在跨构图时才看得出来：

| 镜 | 场景 |
|---|---|
| 镜 2 | ① 远景 · 清晨草地（全身） |
| 镜 3 | ② 中景 · 窗边侧脸 |
| 镜 4 | ③ 近景 · 雨中街道（正面） |

| | A 组 | B 组 |
|---|---|---|
| 一致性档位 | **L1** 只有文字锚定 | **L1 + L2**（文字锚定 + 参考图 img2img） |
| 提示词 | `{NAOKO}` → 冻结的锚定描述 | 同上（**一样**，不是"B 多写了描述"） |
| 参考图 | 无 | 定妆照 `cand-01.png`（1.39 MB，已上传到 ComfyUI） |
| 工作流 | `zimage_turbo.json`（纯文生图） | `zimage_scene_ref.json`（LoadImage→VAEEncode→KSampler） |
| denoise | — | 0.55 |
| seed | `42 + 镜号` | 同左（**故意一样**，只让参考图成为变量） |

---

## 判断时看这三点

1. **B 的三张脸，是不是比 A 更像同一个人**（对照左上角那张定妆照）
2. **B 有没有"换脸色/换发型"** —— denoise 调太高就会换脸
3. **B 有没有"场景没画出来"** —— denoise 调太低就只是把定妆照重画一遍

> 如果 2 或 3 出了问题，调 `[cast].ref_denoise`（默认 0.55，
> 区间 0.45–0.60：**越高越自由、越低越贴参考图**）。**不用改模板。**

## 怎么自己再跑一遍

```powershell
$P = ".venv\Scripts\python.exe"

# 起 ComfyUI（约 90 秒）
D:\ComfyUI\start_comfyui.cmd

& $P -m lvs run ".demo\稿.md" --task DEMO-B --config ".demo\B-带参考图.toml" --no-llm --skip-gates
# 成片：.work\DEMO-B\final.mp4

# 换个 denoise 再试（改 .demo\B-带参考图.toml 里的 cast.ref_denoise，然后）
Remove-Item ".work\DEMO-B\assets" -Recurse -Force     # 清掉旧图才会重出
& $P -m lvs assets --task DEMO-B --config ".demo\B-带参考图.toml"
& $P -m lvs build  --task DEMO-B --config ".demo\B-带参考图.toml"
```

> ⚠️ 演示用的是**临时定妆库**（`.demo/cast/lock.json`，我把 NAOKO 标成了已批准），
> **没有动你真正的定妆库**。要在正式项目里启用 L2，得先
> `lvs cast --approve NAOKO`（见 `docs/一致性现状核对.md`）。

## 两点如实说明

1. **脸部放大格是按"画面上中部"裁的**，不是人脸检测框出来的
   （人脸模型在你机器上不可用，见 `docs/一致性现状核对.md` 第四节）。
   如果某张构图偏了、裁歪了，**以整图那一行为准**。
2. **配音用的是免费联网的 edge**（zh-CN-YunxiNeural），不是你本地的
   `voice-F-clean-youth` —— 演示本机 TTS 服务没开。**画面才是要比较的东西**，
   配音只是为了成片完整。
